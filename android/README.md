# NextMe Android

Android 8.0+ preview app, package `com.salgro.nextme`. This is a signed debug APK for direct testing, not a Play Store release.

## App behaviour

The APK includes the latest NextMe frontend as a clearly labelled offline sample. Tap **Connect**, enter the root HTTPS URL of your deployed independent NextMe website and sign in there to use private diaries, goals, AI and account sync. The site must run the backend and configured AI services. No live site is assumed, and the old AppDeploy deployment is not hardcoded.

Only connect to a website you trust. The Android app stores the chosen site address locally and uses normal first-party web sessions. Changing websites clears local web cookies/storage. It rejects cleartext HTTP, blocks file access, uses verified TLS and exposes no JavaScript-to-native bridge. External HTTPS links open in the browser. Android backup is disabled for app data.

The APK does not include the Node/SQLite backend or any AI secret. Offline sample changes are not private, durable account records. Deploy the server separately.

**Android WebView limitations:** native push notifications are not implemented. Open the site through Menu → Open in browser to enable browser reminders. Journal/summary/calendar downloads should also be completed there. Browser narration depends on WebView support. This is a web-based Android client, not a native video-calling app.

## Build

Requirements: Node 24, JDK 17, Android SDK platform 35/build-tools 35.0.0. Set ANDROID_HOME or configure Android Studio's SDK path in an untracked `local.properties`.

```sh
npm ci
npm run android:prepare
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`.

The GitHub Actions Android workflow builds an installable preview artifact on selected pushes or manual dispatch. Debug signing keys are generated by the build machine; a build from a different machine can require uninstalling a previously installed preview first. Never commit signing keys. A production release requires a privately maintained signing key, release configuration, device testing and Play Store preparation if desired.
